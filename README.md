Thí nghiệm cho kim loại kiềm (Li, Na, K) tác dụng với nước:

2Li + 2H2O --> 2LiOH + H2 
-> Phản ứng êm dịu, H2 sủi bọt từ từ.

2Na + 2H2O --> 2NaOH + H2
-> Na nóng chảy vo tròn thành viên bi, chạy nhanh trên mặt nước, sủi bọt H₂ mạnh.

2K + 2H2O --> 2KOH + H2
-> Phản ứng cực kỳ mãnh liệt, bốc cháy với NGỌN LỬA TÍM, khói dày đặc
